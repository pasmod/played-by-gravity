# Shur in g

An original piece in Dastgāh-e Shur, played by gravity. Two balls are dropped; every tile they land on is a
note. Nothing about the balls is animated: a physics simulation carries them, and the page draws it live.

**Play it: https://pasmod.github.io/shur-in-g/**

## What is in this repository

- `index.html`, `player.js`: the page, the sound clock and the controls
- `app.js`: the picture, drawn with three.js from the time alone
- `scene.js`: the result of the physics run (tiles, trajectories, collisions)
- `setar.m4a`, `santur.m4a`: the sound, computed from the collisions by a model of a setar and of a santur (no samples)
- `fonts/`: Cormorant Garamond and Vazirmatn, both under the SIL Open Font License

The page explains how the piece was made.
